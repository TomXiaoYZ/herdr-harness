# Generated-UI Defaults to Refuse

These are the defaults models fall into regardless of subject. Each is legitimate when the brief asks for it; reaching for one when the axis is free means no decision was made. Fix by rewriting the element, not by softening it. Lines marked **ban** stay out even when tempting.

## Contents

- Type and labels

## Page scaffolds

- A grid of identical cards (icon + heading + two lines) as the page structure. Use the content's own shape: a table, a list, a comparison, a single strong example.
- The hero-metric template: big number, small label, supporting stats, gradient accent.
- Section numbers `01 / 02 / 03` when the content is not a sequence.
- **Ban:** a card inside a card.
- Every section centered; more centered heading groups than left-aligned ones.
- A modal for a task that needs neither interruption nor protected focus.
- A default run of features → steps → testimonials → email band instead of the category's real anatomy.

## Type and labels

- **Ban:** an eyebrow or kicker label above every heading.
- Labels, table heads, tags, nav links in tracked ALL CAPS or small caps; use the body face a step smaller, sentence case, untracked.
- One word in a headline set in italic, bold, gradient, or a different color.
- Gradient text for emphasis; emphasis comes from size and weight.
- Monospace as a costume for "technical" outside code, data, or measurement.
- The default families (Inter everywhere, a system display face as the brand voice) when the brief leaves type free.

## Color and surface

- Purple-to-blue or indigo gradients; glows, neon halos, zero-offset colored shadows.
- Glassmorphism and backdrop blur as decoration.
- A colored bar down one side of a rounded box (side-stripe border) for status or emphasis; use a full border, a tint, or a leading icon/label.
- Hard offset shadows (`4px 4px 0`) outside a genuinely neobrutalist world.
- The same soft gray shadow and one radius on everything regardless of hierarchy.
- Repeating stripes, grid-paper, or grain backgrounds with no blueprint, map, or canvas under them.
- Light or dark theme chosen by category ("AI tool → dark") instead of by the use scene.

## Icons and imagery

- **Ban:** emoji as icons or section markers; "New ✨" badges.
- Decorative status dots, pulsing dots, sparkle icons.
- Hand-drawn browser or OS window frames; sketch-style SVG scenes; glossy 3D blobs.
- Sparklines, progress rings, and rounded rectangles standing in for real content.

## Motion

- Fade-and-rise entrance on every section; hover lift on every card.
- Pulsing or infinitely animated elements without meaning.
- Scattered effects instead of one authored moment.

## Copy and content

- **Ban:** invented metrics, testimonials, logo walls, or case-study counts.
- Middle-dot-joined meta strings (`A · B · C`), arrows glued to link text (`Learn more →`), `WORD — fragment` labels.
- Marketing filler ("Supercharge your workflow", "Seamless", "Unlock"); system words where user words fit ("webhook config" instead of "notifications").
- More than ~80 words on one landing screen; a hero with more than a headline, one sentence, and its actions.

## Palettes models converge on

Treat these as defaults to justify, not choices:

1. Warm cream background (≈`#F4F1EA`) with a high-contrast serif and a terracotta/clay accent (≈`#D97757`).
2. Near-black background (`#0B0B0B`, `#111`) with one acid-green or vermilion accent.
3. Broadsheet layout: hairline rules, zero radius, dense newspaper columns.
4. SaaS card kit: identical rounded cards, one radius, `rgba(0,0,0,.1)` shadow, gradient washes.

## Fix order

When many tells are present, fix in this order so later passes do not redo earlier ones: spacing → color → icons → copy → type → layout → details → visuals → motion. For a full pass with a direction derived from the product, run the `unslop` skill.
